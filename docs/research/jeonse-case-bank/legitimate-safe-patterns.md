# 정상 매물이 갖추는 조건 (safe 판정 매물 작성용 1차 자료)

`risky: false`(정답 X = 안전)인 매물을 만들 때 근거로 삼는 자료. "위험 신호가 없다"가
아니라, 보증금 회수 여력을 뒷받침하는 **적극적 조건**(낮은 전세가율, 선순위 채권 없음,
소유자 본인 직접 계약, 근저당 설정 금지 특약, 전세보증보험 가입 가능 등)이 갖춰진 상태를
정리한다. 다른 카테고리 파일(위험 패턴)은 "이런 요소가 있으면 위험"이라는 대조군으로만
참고하고, 그 위험 요소를 safe 매물에 이식하지 않는다. 스키마는 [README.md](./README.md) 참고.
