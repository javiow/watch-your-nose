# 문제 없는 계약이 통과하는 조건 (NONE_LIMITED_RISK 케이스용)

`fraud_type_hint: NONE_LIMITED_RISK` 케이스를 만들 때 근거로 삼는 자료. 조사해도 결정적
위험 신호가 나오지 않고, 상대방 진술이 서류와 대체로 일치하며, 최고점 엔딩이 "추가 확인
필요" 또는 "계약 진행 가능"이 되는 상황을 정리한다. 체험자가 이미 "사기 조사"라는 걸 알고
들어오므로 반사적으로 "계약 중단"을 고르기 쉬운데, 그 경우 감점되도록 설계한다. 다른 파일의
위험 패턴은 대조군으로만 참고하고 이식하지 않는다. 스키마는 [README.md](./README.md) 참고.
