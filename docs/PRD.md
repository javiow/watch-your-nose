# PRD: Grill Me

## 목표
실제 금융사기 사례를 사전 안내 없이 체험시켜 사용자의 즉각적 판단력을 테스트하고, 사후에 오답 원인과 대응법을 교육한다.

## 사용자
보이스피싱, 사기 문자/게시물, 전세사기 등 금융 사기 위험에 노출될 수 있는 일반 사용자.

## 핵심 기능
1. 랜딩 — 서비스명 "Watch Your Nose" + 헤드라인 "눈 뜨고 코 베인다"로 도발적으로 이목을 끌고, 규칙(총 3단계 · 선택 후 "다음" 클릭 · 결과는 마지막에 공개)만 간단히 안내한다. 어떤 유형이 나올지는 알려주지 않는다.
2. 3개 체험 유형(보이스피싱 / 사례선택 / 전세매물)을 매 세션 랜덤 순서 · 랜덤 콘텐츠로 유형당 1개씩 총 3단계 체험. 선택 직후 정답/오답 피드백 없이, 사용자가 "다음"을 눌러야 다음 단계로 진행.
3. 보이스피싱 — 선택지 기반 분기 대화. 사기 시나리오 사이에 정상 케이스도 섞여 있으며, 사기 케이스 거절은 정답, 정상 케이스 거절은 오답으로 채점("무조건 거절" 패널티).
4. 사례선택 — 사기/정상 사례 쌍 중 사기로 의심되는 쪽 선택.
5. 전세매물 — 정상/사기 매물 쌍 중 정상 매물 선택.
6. 종합 결과 리포트 — 유형별 정답률(%)+등급, 3개 유형 평균으로 종합 등급, 문항별 상세 리뷰(내 선택 vs 정답, 이유), 오답 유형별 대응 방안, "다시 체험하기"(랜딩 스킵하고 바로 재시작; 별도 "처음으로" 버튼 없음).

## MVP 제외 사항
- 회원가입/로그인, 서버 측 결과 저장 (백엔드 없음, 완전 정적 데이터)
- LLM 기반 실시간 자유 대화·평가
- 이어하기/재개 — 새로고침·이탈 시 매번 처음부터 재시작
- 관리자용 콘텐츠 입력 UI (콘텐츠는 데이터 파일로 직접 추가)
- 배포 (이번 단계는 로컬 실행 확인까지만)
- 리더보드/소셜 공유

## 디자인
