# PRD: Grill Me

## 목표
실제 금융사기 사례를 사전 안내 없이 체험시켜 사용자의 즉각적 판단력을 테스트하고, 사후에 오답 원인과 대응법을 교육한다.

## 사용자
보이스피싱, 사기 문자/게시물, 전세사기 등 금융 사기 위험에 노출될 수 있는 일반 사용자.

## 핵심 기능
1. 랜딩 — 서비스명 "Watch Your Nose" + 헤드라인 "눈 뜨고 코 베인다"로 도발적으로 이목을 끌고, 규칙(총 3단계 · 선택하면 진행됨 · 결과는 마지막에 공개)만 간단히 안내한다. 어떤 유형이 나올지는 알려주지 않는다.
2. 랜딩 직후 캐릭터 설정 — 나이대/직업/성별을 한 번 선택한다. 화면에는 노출하지 않고 향후 시나리오 매칭에 사용할 목적으로만 저장한다(재시작 시에는 다시 묻지 않음).
3. 3개 체험 유형(보이스피싱 / 사례선택 / 전세매물)을 매 세션 랜덤 순서 · 랜덤 콘텐츠로 유형당 1개씩 총 3단계 체험. 선택 직후 정답/오답 피드백 없이 다음 단계로 진행한다. 사례선택/전세매물은 선택 후 "다음" 버튼을 눌러야 진행되고, 보이스피싱은 채팅형 UI로 선택지를 클릭하면 즉시 대화가 이어진다.
4. 보이스피싱 — 채팅형 분기 대화(가해자/피해자가 말풍선을 주고받는 방식, 타이핑 인디케이터 연출, 선택지 클릭 즉시 진행). 콘텐츠 풀은 "사기같은 정상 케이스" 2개 + "정상같은 사기 케이스" 2개로 구성해 표면적 인상과 실제 정답이 어긋나도록 설계한다. 사기 시나리오를 거절하면 정답, 정상 시나리오를 거절하면 오답("무조건 거절" 패널티), 사기 시나리오에 응하면 오답("사기에 넘어감" 패널티)으로 채점.
5. 사례선택 — 사기/정상 사례 쌍 중 사기로 의심되는 쪽 선택.
6. 전세매물 — 골목 맵을 이동하며 매물 5채를 방문해 등기부·전세가율 등 8개 서류 항목을 확인하고 위험 여부를 O/X로 판정한다. 판정 직후에는 정답을 알려주지 않으며(다른 유형과 동일한 원칙), 5채 판정을 종합해 하나의 성적으로 채점한다.
7. 종합 결과 리포트 — 유형별 정답률(%)+등급, 3개 유형 평균으로 종합 등급, 문항별 상세 리뷰(내 선택 vs 정답, 이유), 오답 유형별 대응 방안, "다시 체험하기"(랜딩 스킵하고 바로 재시작; 별도 "처음으로" 버튼 없음).

## MVP 제외 사항
- 회원가입/로그인, 서버 측 결과 저장 (백엔드 없음, 완전 정적 데이터)
- LLM 기반 실시간 자유 대화·평가
- 이어하기/재개 — 새로고침·이탈 시 매번 처음부터 재시작
- 관리자용 콘텐츠 입력 UI (콘텐츠는 데이터 파일로 직접 추가)
- 배포 (이번 단계는 로컬 실행 확인까지만)
- 리더보드/소셜 공유
- 캐릭터 정보 기반 시나리오 매칭/개인화 (정보는 수집만 하고 이번 범위에서는 사용하지 않음)

## 디자인
- 다크모드 고정, 미니멀. 장식적 그라데이션/블러 글로우/보라색 브랜드 컬러 등 AI 템플릿 티가 나는 장식은 지양한다.
- 메인 포인트 컬러: 블루. 시맨틱 색: 정답/안전 green, 오답/위험 red.
- 모바일 반응형 필수 (전화·문자 상황을 다루는 서비스 특성상 모바일 사용 비중이 높을 것으로 예상).
