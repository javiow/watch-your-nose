# PRD: Grill Me

## 목표
실제 금융사기 사례를 사전 안내 없이 체험시켜 사용자의 즉각적 판단력을 테스트하고, 사후에 오답 원인과 대응법을 교육한다.

## 사용자
보이스피싱, 사기 문자/게시물, 전세사기 등 금융 사기 위험에 노출될 수 있는 일반 사용자.

## 핵심 기능
1. 랜딩 — 서비스명 "Watch Your Nose" + 헤드라인 "코심코심"("코 조심"을 반복한 말놀이)으로 도발적으로 이목을 끄는 히어로 화면. 마스코트 주변에 뜨는 장식용 알림 카드는 데스크톱뿐 아니라 모바일에서도 노출된다. "시작하기"를 누르면 서비스 소개와 진행 방식(여러 단계 · 각 콘텐츠를 마치면 버튼을 눌러야 다음으로 진행 · 결과는 마지막에 공개)을 안내하는 별도 소개 페이지(`/how-it-works`)를 거친 뒤 캐릭터 설정으로 이동한다. 어떤 유형이 나올지는 알려주지 않는다.
2. 랜딩 직후 캐릭터 설정 — 나이대/직업/성별을 한 번 선택한다. 화면에는 노출하지 않고 향후 시나리오 매칭에 사용할 목적으로만 저장한다(재시작 시에는 다시 묻지 않음).
3. 난이도 선택 — 캐릭터 설정 직후, 쉬움 / 중간 / 어려움 중 하나를 선택한다. 각 난이도에는 한 줄 설명이 붙되 어떤 체험 유형이 나올지는 드러내지 않는다(일반적 표현만). 선택한 난이도는 이후 각 체험이 콘텐츠를 고를 때 필터로 쓰인다 — 해당 난이도로 태깅된 콘텐츠 중에서 랜덤 선택하며, 태깅이 없는 유형은 전체 콘텐츠에서 랜덤한다. 재시작 시에는 다시 묻지 않는다.
4. 4개 체험 유형(보이스피싱 / 케이스 조사 / 전세매물 / 사기 판별 카드)을 매 세션 랜덤 순서 · 선택한 난이도 내 랜덤 콘텐츠로 유형당 1개씩 총 4단계 체험. 유형 내부의 진행 방식은 유형마다 다르다(케이스 조사/전세매물은 선택 후 "다음" 버튼을 눌러야 진행되고, 보이스피싱은 채팅형 UI로 선택지를 클릭하면 즉시 대화가 이어진다). 다만 한 유형의 콘텐츠를 모두 마치면 정답/오답 피드백 없이, 화면에 남은 "다음으로 넘어가기" 버튼을 직접 눌러야만 다음 유형으로 넘어간다(4개 유형 공통, 자동 전환 없음).
5. 보이스피싱 — 채팅형 분기 대화(가해자/피해자가 말풍선을 주고받는 방식, 타이핑 인디케이터 연출, 선택지 클릭 즉시 진행). 콘텐츠 풀은 "사기같은 정상 케이스"와 "정상같은 사기 케이스"를 섞어 표면적 인상과 실제 정답이 어긋나도록 설계하며(정상 4 + 사기 6, 총 10개), 각 시나리오에 난이도(쉬움/중간/어려움)를 매겨 쉬움/중간/어려움마다 정상·사기가 모두 포함되도록 배분한다. 사기 시나리오를 거절하면 정답, 정상 시나리오를 거절하면 오답("무조건 거절" 패널티), 사기 시나리오에 응하면 오답("사기에 넘어감" 패널티)으로 채점.
6. 케이스 조사 — 전세·청약·분양 계약 상황을 조사한다. 조사 포인트로 문서(등기부·시세·중개사 대응 등)를 열람해 위험 신호를 증거로 등록하고, 상대방(중개사·상담사·가족 등)에게 정해진 질문을 건네 고정된 대사를 듣는다. 마지막에 "계약 진행 가능 / 추가 확인 필요 / 계약 중단" 중 하나로 최종 판단한다. 판단 직후에는 정답을 알려주지 않으며(다른 유형과 동일한 원칙), 케이스별로 최고점 선택지가 다르다(위험 신호가 경미한 케이스는 "진행 가능"이 최고점일 수 있다).
7. 전세매물 — 골목 맵을 이동하며 매물 5채를 방문해 등기부·전세가율 등 8개 서류 항목을 확인하고 위험 여부를 O/X로 판정한다. 판정 직후에는 정답을 알려주지 않으며(다른 유형과 동일한 원칙), 5채 판정을 종합해 하나의 성적으로 채점한다.
8. 사기 판별 카드 — 실제 공개된 사기 유형(중고거래·투자리딩방·로맨스스캠·스미싱 등 19종) 기반의 서술형 지문 카드 4장을 연달아 보고 각각 "사기예요"/"정상이에요"로 판정한다. 판정 직후에는 정답을 알려주지 않으며(다른 유형과 동일한 원칙), 4장 판정을 종합해 하나의 성적으로 채점한다. 출처(source)는 정답을 암시할 수 있어 해설과 함께 결과 페이지에서만 노출한다.
9. 종합 결과 리포트 — 유형별 정답률(%)+등급, 4개 유형 평균으로 종합 등급, 문항별 상세 리뷰(몇 번이 어떤 체험 유형이었는지 라벨 + 내 선택 vs 정답, 이유), 오답 유형별 대응 방안(어떤 체험 유형에서 나온 피드백인지 라벨 포함), "다시 체험하기"(랜딩 스킵하고 바로 재시작; 별도 "처음으로" 버튼 없음).

## MVP 제외 사항
- 회원가입/로그인, 서버 측 결과 저장 (백엔드 없음, 완전 정적 데이터)
- LLM 기반 실시간 자유 대화·평가
- 이어하기/재개 — 새로고침·이탈 시 매번 처음부터 재시작
- 관리자용 콘텐츠 입력 UI (콘텐츠는 데이터 파일로 직접 추가)
- 배포 (이번 단계는 로컬 실행 확인까지만)
- 리더보드/소셜 공유
- 캐릭터 정보 기반 시나리오 매칭/개인화 (정보는 수집만 하고 이번 범위에서는 사용하지 않음)
- 케이스 조사·사기 판별 카드 콘텐츠의 난이도 태깅 — 전세매물·보이스피싱은 난이도별 필터가 실제로 동작하고, 이 2개 유형은 아직 전체 콘텐츠에서 랜덤(난이도 태깅은 후속 작업)

## 디자인
- 라이트 테마 고정. 배경은 따뜻한 크림(`--background`), 텍스트는 짙은 브라운(`--foreground`), 카드 표면은 흰색. 색·폰트·간격은 `src/app/globals.css`의 디자인 토큰(`:root` + `@theme inline`)을 단일 출처로 쓴다.
- 메인 포인트 컬러: 번트오렌지(`--accent` `#e8623a`). 시맨틱 색: 정답/안전 green(`--safe`), 오답/위험 red(`--danger`).
- 랜딩은 히어로 중심의 몰입형 화면을 허용한다 — 인터랙티브 마스코트, 브랜드 토큰 범위 내의 은은한 배경 그라디언트/그레인, 커서 반응, 스크롤 유도. 단 보라색 브랜드 컬러·블러 글로우·과한 그림자 등 "AI 템플릿 티"가 나는 장식은 계속 지양하고, `prefers-reduced-motion`을 존중한다.
- 모바일 반응형 필수 (전화·문자 상황을 다루는 서비스 특성상 모바일 사용 비중이 높을 것으로 예상).
